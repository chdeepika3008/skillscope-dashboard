
# skillscope-dashboard

## Project Overview
This project analyzes live job postings and displays trending technical skills using an interactive dashboard built with Python and Streamlit.

## Features
- Fetches live job data from API
- Analyzes trending skills
- Displays charts and analytics
- Interactive dashboard

## Technologies Used
- Python
- Streamlit
- Pandas
- Requests
- Plotly

## Project Structure

SkillScopeProject/
│
├── app.py
├── scraper.py
├── requirements.txt
└── README.md


## Installation

pip install -r requirements.txt

## Run the Project

streamlit run app.py

## Dashboard Preview

The dashboard shows:

* Top skills in demand
* Skill distribution charts
* Job analytics
